# LifeDesk Windows Installer 要求记录

## 目标

将当前项目打包为一个可在 Windows 桌面正式安装和长期使用的软件，最终交付物应为安装版 `Setup.exe`，而不是仅可解压运行的便携版程序目录。

## 最终交付要求

- 必须生成 Windows 安装版 `Setup.exe`
- 不接受只提供 `LifeDesk.exe`
- 不接受只提供 `win-unpacked`
- 不接受只提供便携版压缩包代替安装器
- 安装完成后，软件应能像正常 Windows 软件一样被用户长期使用

## 安装器要求

- 必须提供标准安装流程
- 安装时应允许用户选择安装目录
- 应支持安装到 `D:\Apps\LifeDesk`
- 应创建桌面快捷方式
- 应创建开始菜单快捷方式
- 应支持正常卸载

## 数据目录要求

- 运行数据不能默认写入 `C:\Users\用户名\AppData\...`
- 不能默认使用 Electron 的 `userData` 作为首选落点
- 运行数据和 SQLite 数据库应默认优先写入 `D:\LifeDeskData`
- SQLite 数据库默认路径应为 `D:\LifeDeskData\runtime-data\lifedesk.sqlite`
- 只有在 `D:` 盘不可用时，才允许回退到系统默认用户目录
- 最好保留可配置能力，以便后续改为其他盘符或目录

## 对 SQLite 的要求理解

- SQLite 是本地文件数据库
- 数据库存放位置应由项目明确控制
- 不能因为桌面封装后就擅自改成默认写入 `C` 盘用户目录
- 安装目录与数据目录可以不同
- 程序安装在 `D:\Apps\LifeDesk`，数据放在 `D:\LifeDeskData`，这是可接受且推荐的方案

## 使用场景要求

- 这是用户本人长期在 Windows 电脑上安装使用的软件
- 目标是正式安装版软件，不是测试版或临时运行版
- 应优先考虑稳定性、可维护性、安装体验和数据路径可控性

## 非目标

- 不要求只生成一个独立单文件 exe
- 不以“先跑起来”为唯一目标
- 不接受只解释原理但不给最终安装版结果

## 验收标准

- 最终存在可执行的 `Setup.exe`
- 安装器可正常运行
- 安装目录可选，且可安装到 `D:\Apps\LifeDesk`
- 安装后软件可正常启动
- 默认运行数据落在 `D:\LifeDeskData\runtime-data\lifedesk.sqlite`
- 卸载流程正常
- 不能以便携版或中间产物代替最终安装器

## 环境说明

- 如果当前环境无法直接生成 `Setup.exe`，必须明确说明缺少的系统依赖或打包条件
- 如果需要切换到 Windows 环境完成最后一步，应给出准确的执行命令和操作步骤
